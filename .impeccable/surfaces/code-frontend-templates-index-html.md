# Shine 首页

Mode: Operate. 面向项目所有者的日常听歌、找歌和收藏整理。

## Direction contract

- **视觉** 使用暖白背景、近白面板与暖灰细边框。搜索、主播放与选中分类使用较深的暖白底和深暖灰文字或图标，播放时的环境光为浅暖色。
- **布局** 沿用顶栏、桌面搜索／播放器与歌词／音乐库三栏及独立滚动。窄屏依次显示播放器、搜索和音乐库，保留快捷导航。
- **操作** 搜索后主动选曲并建立播放队列。浏览收藏、歌单与下载时沿用当前队列。歌词按钮与 L 在清晰、强调两种无光晕样式间切换。
- **素材** 头像来自用户提供的 1000295373.jpg，使用 CSS 圆形裁切。默认唱片插画来自用户提供的 codex-clipboard-bf769006-55fe-4f09-ae6c-9e785ef4d839.png，完整保留构图。
