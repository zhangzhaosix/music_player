# Shine 音乐播放器

一个基于 Flask 的个人音乐网页，支持在线搜索、试听、下载、收藏和歌单管理。

在线搜索、播放解析和歌词只通过落月 API 的 QQ 音乐目录获取，停用原酷我、网易云接口。同歌名、同歌手、同版本的重复搜索结果合并；明确不同的录音版本保留。播放地址通过落月 API 直接解析，不需要安装洛雪客户端或运行第三方音源脚本。

## 功能

- 在线搜索先核验落月播放地址，并用最多 1 KB 的音频开头排除空文件、错误页和非音频响应，再逐条展示；只返回试听、空地址或身份不符的条目隐藏，最多 3 个并发核验，共用 12 秒预算，成功与明确不可用的结果缓存 5 分钟。临时超时、限流不永久排除，提供重新搜索
- 在线试听未下载歌曲
- 下载歌曲到本地 `音乐合集/`
- 收藏歌曲
- 管理歌单
- 记忆音量与播放进度
- 本地歌曲和已有直链优先快速播放，歌词与整曲响度分析异步完成；已分析歌曲按固定增益均衡，保留原有动态
- 响度目标为 −18 LUFS，真实峰值上限为 −2 dBTP，最多提升 6 dB；峰值安全优先，大动态歌曲可能低于目标响度
- 未分析歌曲固定衰减 2 dB，不根据安静前奏猜测整曲音量；后台结果在下次播放生效，不在本次播放途中调整响度
- QQ 在线播放默认使用标准压缩音质，优先保证完整版和稳定性；新 QQ 来源仅提供在线播放、收藏和歌单功能，不提供下载或后台整曲抓取。本地歌曲维持原有行为；旧酷我、网易云收藏和歌单播放时仅通过落月严格匹配同歌手、同版本，不修改原记录；允许下载的音源用 FFprobe 核实真实格式，不重新编码
- 当前音频缓冲稳定后预取队列中的下一首音频；对应预取资源保留至该歌曲开始播放，不预取整个队列；播放复用尚未完成的预取解析，按浏览器原始 Range 请求流式传输，避免重复解析与大量 128 KB 小请求
- 收藏、歌单和恢复播放中的平台歌曲通过落月重新解析或复用 5 分钟有效缓存，避免持久保存的失效地址反复播放失败；普通音频直链与本地文件仍可快速播放
- 原音源失败时，仅恢复同歌名且包含原歌手名单成员的备用音源；兼容旧收藏遗漏合唱歌手、歌手名单顺序不同的情况，继续排除其他歌手和不同版本，不修改原收藏记录
- 当前音频缓冲至少 30 秒（短曲缓冲到结尾）后才启动整曲分析，优先保证起播和缓冲恢复
- 按歌曲来源 ID 获取同步歌词，并在收藏、歌单和本地歌曲之间复用歌词缓存
- 批量选中歌曲后可一键本地下载，已下载歌曲会自动跳过
- 下载页支持批量删除：点击“批量删除”进入勾选模式，可全选当前筛选列表或逐首选择；确认后删除本地文件并同步清理关联收藏与歌单记录。失败项保留勾选并显示原因，便于重试
- 删除本地歌曲与删除歌单使用站内确认弹层，不再调用浏览器原生确认框
- 参考皮卡丘音乐站的深蓝黑霓虹界面：顶部 Shine 与用户头像，桌面搜索、播放器和歌曲列表三栏常驻；中间播放器使用用户提供的唱片插画，完整展示图案、不随播放旋转，取消独立底部播放栏
- 左侧是唯一歌曲搜索区域，歌曲行支持播放、收藏，以及“更多操作”中的加入歌单和下载；右侧默认显示实际播放队列，保留收藏、歌单及下载分类
- 搜索结果逐批显示，搜索不切换右侧分类、不自动播放；点击左侧歌曲后建立当时结果的队列快照，后续结果补充不改变队列
- 搜索服务端总等待最多 12 秒，前端最多 15 秒；来源失败保留已有结果，可重新搜索；同关键词来源请求合并，成功结果缓存 5 分钟，缓存及待处理任务有数量上限
- 播放中确认无可播完整版的条目暂时从搜索、收藏和歌单视图及队列隐藏，保留原记录；5 分钟后可重新核验，本地歌曲不受影响。来源明确标记的试听片段不进入搜索结果；解析、预取及播放取得时长后继续检查。仅凭 30 秒时长不判定试听版，缺少完整曲长或试听标记的短曲保留
- 音乐库分类与播放器支持键盘访问，独立弹层支持焦点循环、Esc 关闭和关闭后返回原操作位置
- 桌面首页固定在当前视口内，歌词和列表独立滚动；收藏批量栏与歌单详情操作栏保持可见；小屏按播放器、搜索、列表顺序纵向布局
- 歌词按钮或 L 快捷键切换霓虹高亮/清晰高亮，模式保存在当前浏览器；输入、中文组合输入和弹窗内不会误触发，不影响播放进度及歌词滚动状态
- 搜索、收藏、下载和歌单统一播放状态与交互反馈，支持小屏触控、长标题省略和完整标题提示
- 点击歌曲名称即可播放；收藏支持一键播放、按需展开的批量管理，整理和下载操作集中在歌曲的“更多操作”菜单
- 播放器可查看真实播放队列并定位当前歌曲；浏览其他分类后切歌仍沿用原来的队列
- 音乐库分类记住本次使用时的滚动位置；按 `/` 或顶部搜索入口快速找歌，搜索期间可更换关键词
- 手动翻阅歌词时暂停自动跟随，点击“回到当前歌词”恢复；连接音频时显示明确的等待状态
- 歌词独立加载并优先复用成功缓存；临时失败自动重试一次，也可点击“重试歌词”，不会中断音频或重置进度
- QQ 旧收藏和歌单继续使用原平台歌曲 ID，通过新接口解析标准音质完整版；解析结果缓存 5 分钟，最多 128 条，歌词独立加载。搜索保留不同录音版本，并合并同录音在不同专辑中的重复条目，并在歌手旁展示真实专辑和版本说明，不凭标题声称原唱
- 小屏缩小唱片插画并扩大触控区域，为歌词和音乐列表保留空间；仅提供中文界面，不增加音源选择、搜索数量选择或快捷键说明面板
- 在线搜索优先歌名、歌手和用户指定版本；未主动搜索的翻唱、伴奏、改编等降低排序，不凭标题声称原唱；收藏、下载及歌单详情可独立筛选，收藏支持播放筛选结果
- 随机下一首排除当前歌曲，随机上一首返回本次播放历史；“列表循环”“随机播放”“单曲循环”的名称与行为一致
- 点击播放后的地址解析、同版本备用尝试和首次缓冲共用 10 秒等待预算；超过时间保留歌曲并提供重试。缓存失效或播放失败会重新解析，识别到片段时仅尝试可确认的同歌手、同录音版本，切歌取消旧播放请求
- 重新打开页面恢复歌曲、队列和进度，默认暂停，避免多个标签页同时发声
- 播放器按参考图布局：桌面插画在左，歌名、进度与播放控制在右；封面容器与右侧信息区上下对齐、自动等高，内部图片与控件位置保持不变。上一首、播放/暂停、下一首位于控制行左侧，音量滑条靠右。手机进度与控制行铺满宽度，音量可直接拖动；滑条触控高度为 44px
- 歌单添加列表排除已加入的歌曲；加载失败提供重试入口，删除成功提示以服务端结果为准
- 歌词时间与节点在加载时缓存，只更新前后两行高亮；无时间戳的歌词静态展示
- 全站统一深蓝星空：开启动态背景后，96 个错落星点、缓慢蓝色光雾与每 3–5 秒出现的明亮长流星形成空间层次，偶尔出现双流星；半透明面板让星光透出，歌词区保留较深阅读底色。顶部开关记住选择，关闭后保留静态星空，暂停音乐不改变背景。手机显示 36 个静态星点、单流星，间隔延长至 6–10 秒；系统减少动态效果、页面隐藏或弹窗打开时停止背景运动

## 技术栈

- 后端：Python + Flask
- 网络请求：Requests
- 前端：原生 HTML / CSS / JavaScript
- 数据存储：`data/favorites.json`、`data/playlists.json`、`data/downloads.json`

## 目录结构

- `AGENTS.md`：项目级协作规则
- `code/backend/app.py`：Flask 主程序与后端 API
- `code/frontend/templates/`：页面模板
- `code/frontend/static/`：前端静态资源
- `data/`：收藏、歌单和下载索引等运行数据
- `音乐合集/`：下载后的本地歌曲
- `tests/`：自动化测试
- `scripts/启动音乐网页.bat`：Windows 启动脚本

## 运行要求

- Python 3.8+
- `pip`
- 整曲分析及新下载格式核验需要 FFmpeg 和 FFprobe；已有歌曲播放不依赖这两个工具

## 本地启动

```bash
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe code\backend\app.py
```

浏览器访问：`http://127.0.0.1:5000`

Windows 下也可以直接双击 `scripts/启动音乐网页.bat`。

FFmpeg/FFprobe 查找顺序：环境变量指定路径、项目 `.cache/tools/ffmpeg/ffmpeg.exe` 与 `ffprobe.exe`、系统 PATH。Windows 构建可从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)列出的发行来源获取。工具目录和分析缓存均在已忽略的 `.cache/` 下，不提交二进制或音频。

整曲分析只解码测量原始音频，缓存位于 `.cache/audio-analysis/`。同一音源并发请求合并，单个后台工作线程优先当前歌曲、仅预分析队列下一首。单曲上限 100 MB，音源下载和测量分别最多 120 秒，缓存最多 256 份测量结果；临时音频在任务结束后删除。在线结果有效期 5 分钟，并按直链与上游版本分别缓存；本地结果按文件名、大小和修改时间区分，分析后记录内容 SHA-256。

默认仅支持单声道、立体声的响度测量。音频分析失败不阻断播放；缺少 FFprobe 时新下载会明确报错，以免将未知格式写为 MP3。未经整曲测量的首播无法保证统一响度或真实峰值达标，源文件已有失真也无法靠增益修复。

## 环境变量

当前项目没有必填环境变量。可选 `FFMPEG_PATH`、`FFPROBE_PATH` 分别指定可执行文件的绝对路径；不需要修改系统 PATH。

## API 概览

### 搜索与播放

- `GET /api/search?q=关键词&source_limit=20`：搜索歌曲，`source_limit` 控制单个来源的抓取数量；默认保留 JSON 响应，`stream=1` 返回 NDJSON 快照，每行含 `results`、`done`、`source_errors`
- `GET /api/song-info?url=歌曲URL&song_ref=歌曲专属引用`：获取播放直链、同步歌词及歌词状态；`playback_only=1` 只解析播放信息，缓存 5 分钟并合并并发请求，`refresh=1` 在播放重试时清除地址及详情缓存并重新解析；`fallback_only=1` 排除当前歌曲引用后尝试同版本备用来源，`budget_ms` 限定剩余等待时间（上限 10000 毫秒）
- 同一接口添加 `lyrics_only=1` 可仅获取歌词与状态，无需重新解析可播放音频；已有歌词缓存可直接返回
- `GET /api/proxy-stream?url=MP3直链`：代理在线播放
- `GET /api/audio-analysis?audio_url=同源播放路径`：查询该音源版本的测量结果；返回 `status`、`version`，就绪时包含 `integrated_lufs`、`true_peak_dbtp`、`loudness_range_lu`、`gain_db` 和实际音频格式
- `POST /api/audio-analysis`：使用 JSON `{ "audio_url": "/api/stream/文件名", "priority": "current" }` 触发后台分析；`priority` 可为 `current` 或 `next`，在线路径必须已由歌曲详情解析或实际播放登记；状态包括 `pending`、`ready`、`silent`、`unavailable`、`busy`、`failed`

### 本地音乐

- `GET /api/music`：获取本地歌曲列表
- `GET /api/stream/<filename>`：播放本地歌曲
- `POST /api/download`：下载歌曲到本地
- `DELETE /api/music/<filename>`：删除本地歌曲

### 收藏与歌单

- `GET / POST / DELETE /api/favorites`
- `GET / POST / PUT / DELETE /api/playlists`

## 常见问题

### 搜索请求如何避免重复？

只请求落月 QQ 搜索接口，同关键词请求合并并复用缓存；同歌名、同歌手、同录音版本只展示一次。重复录音的备用 ID 保留在后台，仅在主地址失败时尝试，最多解析两个严格匹配的候选且共用播放预算。403 不重复重试，429 遵守上游 Retry-After；瞬时连接或服务错误只在预算内重试一次。后端日志记录来源域名、失败阶段、尝试次数及耗时。外部来源拒绝访问或不可用时，代码无法保证完整音源可用，也不会绕过限制。

### 为什么有些歌显示已下载，但本地没找到文件？

本地下载状态同时依赖 `音乐合集/` 和 `data/downloads.json`。如果手动移动或删除了文件，建议重新下载或检查下载索引是否一致。

### 为什么播放或搜索失败？

通常是外部接口临时不可用、网络受限，或者本机代理设置不匹配。可稍后重试，或先确认本机网络权限。

### 为什么有些歌曲仍然没有歌词？

播放器会优先使用搜索结果中的歌曲来源 ID 获取歌词，并在当前服务进程内缓存成功结果；当前条目没有歌词时，会在落月目录内按歌名、歌手严格匹配备用条目。界面会区分“可能为纯音乐或未收录”和“歌词服务暂时不可用”，歌词请求失败不会影响歌曲播放。

## 部署注意事项

- 生产环境请保证 `音乐合集/` 和 `data/` 下的运行数据可读写
- 不要把本地下载歌曲、缓存和临时文件提交到仓库
- 如果部署到 Windows，建议保持 `.venv` 与启动脚本路径一致
- 外部接口可能受网络环境影响，部署后如出现搜索失败，优先检查网络与代理

## 收藏音源核验

`python scripts/audit_favorites.py` 仅核验收藏的原有音源，不搜索替代版本。报告写入已忽略的 `.cache/favorites-audit-*/report.json`，包含歌名、歌手、实际时长、完整曲长（若来源提供）及判定依据。来源连续不可用时停止重复请求，其余相关歌曲列为未核验并保留。

先检查清单，再运行 `python scripts/audit_favorites.py --apply 报告路径`，仅删除报告中证据确凿的条目。应用前校验收藏快照和具体歌曲身份，原始收藏备份保存在 `.cache/favorites-before-audit-*.json`，通过原子替换写入收藏；歌单及本地文件不会改变。无法确认实际时长、正常短曲和网络失败项不会删除。

## 音源限制

落月 API 的 QQ 搜索与解析目前无需本项目提供账号或密钥；外部服务的可用性、免费政策和曲库覆盖可能变化。一次核验成功不代表所有歌曲、所有版本都可用。仅缓存地址及歌曲信息，不自动把在线音频保存到音乐目录；地址有效时复用，过期后仍需联网解析。遇到授权、限流、封禁或指定版本缺失时明确报错，不绕过访问限制。

接口说明：[QQ 搜索](https://doc.vkeys.cn/v2/音乐模块/QQ音乐/3-search.html)、[播放地址](https://doc.vkeys.cn/v2/音乐模块/QQ音乐/2-geturl.html)。
